# 🔗 URL Shortener

A simple and efficient URL Shortener built with **Node.js, Express.js, MongoDB, Mongoose, ShortID, and EJS**.

The application converts long URLs into short, easy-to-share URLs and tracks the number of times each shortened URL is accessed along with the timestamp of every click.

##  Features

- Generate short URLs using ShortID
- Redirect short URLs to original URLs
- Store URL data in MongoDB
- Track total clicks
- Store timestamp of every click
- View URL analytics
- Server-side rendering using EJS
- MVC architecture
- Environment variables using dotenv
- Request logging middleware

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- ShortID
- EJS
- dotenv
